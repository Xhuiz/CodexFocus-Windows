# Support

Codex Focus Windows is a Windows utility for Codex Desktop and Douyin. It switches to Douyin while Codex is working, then pauses Douyin and returns to Codex when Codex completes, fails, aborts, or waits for approval.

中文定位：Codex 抖音自动切换工具。

## Before Opening An Issue

Please check these pages first:

- Download page: https://xhuiz.github.io/CodexFocus-Windows/download.html

## What To Include

For bug reports, include:

- Windows version.
- Codex Desktop version, if available.
- Whether Douyin Windows client is running.
- Whether Codex and Douyin windows are detected by the app.
- The recent event log shown in Codex Focus Windows.
- Steps that reproduce the issue.

Do not share private Codex prompts, transcripts, credentials, tokens, or personal data.

## Where To Ask

Use GitHub Issues for bugs and feature requests:

https://github.com/Xhuiz/CodexFocus-Windows/issues

## Scope

The current version primarily targets the Douyin Windows client. Browser-based Douyin, Bilibili, YouTube, or other media apps may require separate adaptation.
