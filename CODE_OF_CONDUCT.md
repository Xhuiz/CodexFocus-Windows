# Code of Conduct

CodexFocus-Windows is a small project around Codex Desktop, Douyin, Windows automation, and AI coding productivity workflows.

## Expected Behavior

- Be respectful and constructive.
- Keep bug reports and feature requests focused on the project.
- Do not post private Codex prompts, transcripts, credentials, tokens, or personal data.
- Assume good intent, but be precise when discussing bugs or risks.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Sharing another person's private data.
- Posting secrets, credentials, tokens, or private transcript content.
- Repeated off-topic comments that make project maintenance harder.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that violate this code of conduct. Serious or repeated violations may result in blocked participation.
