一句话介绍

Codex Focus Windows 是一个 Codex 抖音自动切换工具：Codex Desktop 工作时自动切到抖音，任务完成或等待权限确认时暂停抖音并切回 Codex。

短文案

我做了一个 Windows 小工具 Codex Focus Windows。它会在 Codex Desktop 执行任务时自动切到抖音 Windows 客户端；当 Codex 完成、失败、中断或等待权限确认时，自动暂停抖音并切回 Codex。适合经常让 Codex 跑长任务的人。

长文案

用 Codex Desktop 跑任务时，经常会有一段等待时间。我做了 Codex Focus Windows 来处理这个小工作流：Codex 开始工作后自动切到抖音，Codex 需要你处理时自动暂停抖音并回到 Codex。它基于 .NET 8 和 WPF 实现，读取本机 Codex transcript 判断任务状态，通过 Windows 窗口激活完成切换。项目地址：https://github.com/Xhuiz/CodexFocus-Windows
