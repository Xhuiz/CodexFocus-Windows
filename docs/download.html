下载 Codex Focus Windows v0.1.0。它是 Windows 上的 Codex 抖音自动切换工具：Codex Desktop 工作时自动切到抖音，任务完成、失败、中断或等待权限确认时暂停抖音并切回 Codex。

下载和启动步骤

  1. 安装 .NET 8 Desktop Runtime。
  2. 从 GitHub Release 下载 CodexFocus-Windows-v0.1.0-win-x64.zip。
  3. 解压 zip，运行 CodexFocus.Windows.exe。
  4. 打开 Codex Desktop 和抖音 Windows 客户端。
  5. 确认工具能检测到两个窗口，保持自动监听开启或手动开始监听。

适合谁下载

如果你经常让 Codex Desktop 执行较长任务，又容易在等待期间错过任务完成或权限确认，这个工具适合尝试。它只读取本机 Codex transcript 判断状态，不上传数据，也不自动操作 Codex 输入。
