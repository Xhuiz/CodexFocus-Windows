Codex Focus Windows使用指南

Codex 执行任务时如何自动切到抖音

如果你在 Windows 上使用 Codex Desktop，经常会遇到一个小问题：Codex 正在跑任务时你想临时看抖音，但 Codex 完成或等待权限确认时又容易错过。Codex Focus Windows 就是为这个工作流做的自动切换工具。

下载 Windows 版 查看 GitHub 仓库

它解决的具体问题

Codex Focus Windows 会读取本机 Codex Desktop 的 session transcript。当 Codex 开始执行任务时，它自动激活抖音 Windows 客户端；当 Codex 完成、失败、中断或等待权限确认时，它暂停抖音并切回 Codex。

一句话：Codex 工作时切到抖音，需要你处理时切回 Codex。

适合哪些搜索场景

  • Codex 抖音自动切换工具
  • Codex 自动暂停抖音
  • Codex 等待权限确认自动切回
  • Codex Desktop Douyin auto switch
  • Windows 上的 AI 编程等待工具

使用步骤

  1. 安装 .NET 8 Desktop Runtime。
  2. 打开 Codex Desktop。
  3. 打开抖音 Windows 客户端。
  4. 下载并解压 CodexFocus-Windows-v0.1.0-win-x64.zip。
  5. 启动 Codex Focus Windows，确认界面能检测到 Codex 和抖音窗口。
  6. 保持自动监听开启，之后让 Codex 正常执行任务。

注意事项

当前版本主要面向抖音 Windows 客户端，不保证浏览器版抖音可用。工具只读取本机 Codex transcript 来判断任务状态，不上传数据，也不会替你操作 Codex 输入内容。
