Codex Focus Windows使用场景

Codex 长任务等待时自动切到抖音

这个使用场景面向经常让 Codex Desktop 执行长任务的 Windows 用户。Codex Focus Windows 会在 Codex 工作时自动切到抖音 Windows 客户端；当 Codex 完成、失败、中断或等待权限确认时，暂停抖音并切回 Codex。

典型场景

等待长任务

让 Codex 处理构建、重构、分析或多文件修改时，临时切到抖音，不需要手动找窗口。

不错过确认

Codex 等待权限确认或需要用户输入时，工具暂停抖音并切回 Codex，减少漏看确认的情况。

减少手动切换

把“Codex → 抖音 → Codex”的窗口切换自动化，适合重复等待的 AI 编程工作流。

工作流

  1. 打开 Codex Desktop 和抖音 Windows 客户端。
  2. 启动 Codex Focus Windows，并保持监听开启。
  3. Codex 开始任务后，工具自动切到抖音并继续播放。
  4. Codex 完成、失败、中断或等待权限确认时，工具暂停抖音并切回 Codex。
  5. 查看结果或处理确认请求后，继续下一轮 Codex 任务。

适合和不适合

适合

Windows、Codex Desktop、抖音 Windows 客户端、经常有几分钟以上的 Codex 等待时间。

谨慎使用

如果你的 Codex 任务很短，建议把 TaskSwitchDelaySeconds 调到 1 到 3 秒，避免来回切换。

暂不保证

浏览器版抖音、B 站、YouTube 或其他媒体软件，需要单独适配窗口匹配和播放暂停逻辑。
