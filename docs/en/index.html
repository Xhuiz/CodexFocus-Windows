Codex Focus Windows中文

Codex works. Douyin plays. You come back when Codex needs you.

Codex Focus Windows is a Windows utility for Codex Desktop and the Douyin Windows client. It switches to Douyin while Codex is working, then pauses Douyin and returns to Codex when Codex completes, fails, aborts, or waits for approval.

What it does

Watches Codex

Reads local Codex Desktop session transcript files to detect task state.

Switches to Douyin

Activates the Douyin Windows client when Codex starts a task.

Returns to Codex

Pauses Douyin and switches back when Codex needs user attention.

Requirements

  • Windows
  • .NET 8 Desktop Runtime
  • Codex Desktop
  • Douyin Windows client
