Codex Focus Windows 是一个 Windows 桌面工具，用来自动衔接 Codex Desktop 和抖音 Windows 客户端。它读取本机 Codex transcript 判断任务状态，然后完成窗口切换和播放/暂停。

它具体做什么

这个工具不控制 Codex，也不上传数据。它只在本机读取 Codex Desktop 的任务 transcript，并通过 Windows 窗口激活完成切换。

01

监听 Codex 状态

读取 `%USERPROFILE%\.codex\sessions` 下的 Codex Desktop transcript，识别任务开始、完成、中断和权限确认。

02

自动切到抖音

Codex 开始工作后，激活抖音 Windows 客户端，并向窗口中心发送点击来继续播放。

03

暂停并切回 Codex

当 Codex 完成、失败、中断或等待权限确认时，自动暂停抖音并把窗口切回 Codex。

FAQ

Codex Focus Windows 是什么？

它是一个 Codex Desktop 和抖音 Windows 客户端之间的自动切换工具。Codex 工作时自动切到抖音，Codex 需要你处理时自动暂停抖音并切回 Codex。

它会控制 Codex 或上传数据吗？

不会。它只读取本机 Codex Desktop transcript 来判断任务状态，不上传数据，也不自动操作 Codex 的输入内容。

支持网页版抖音吗？

当前版本优先支持抖音 Windows 客户端，不保证浏览器版抖音可用。

需要安装什么？

需要 Windows、.NET 8 Desktop Runtime、Codex Desktop 和抖音 Windows 客户端。
