常见问题

有没有 Codex 自动切换抖音的软件？

有。Codex Focus Windows 是一个面向 Windows 的 Codex 抖音自动切换工具。Codex Desktop 工作时自动切到抖音 Windows 客户端，任务完成、失败、中断或等待确认时暂停抖音并切回 Codex。

Codex 执行任务时可以自动切到抖音吗？

可以。工具读取本机 Codex Desktop 的 session transcript，识别任务开始后激活抖音 Windows 客户端，并通过窗口中心点击继续播放。

Codex 等待权限确认时能不能自动切回？

可以。检测到 Codex 等待权限确认、任务完成、任务失败或中断后，Codex Focus Windows 会暂停抖音并切回 Codex 窗口。

Codex Focus Windows 会上传 Codex 内容吗？

不会。它只读取本机 Codex transcript 来判断状态，不上传用户数据，也不会向 Codex 输入提示词或操作 Codex 内容。

这个工具支持网页版抖音吗？

当前版本主要面向抖音 Windows 客户端。浏览器版抖音、B 站、YouTube 或其他视频软件需要额外适配窗口匹配和播放暂停逻辑。

Codex 抖音自动切换工具在哪里下载？

可以从 GitHub Release 下载 Windows zip。源码仓库是 github.com/Xhuiz/CodexFocus-Windows。
