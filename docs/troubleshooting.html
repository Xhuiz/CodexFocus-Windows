Codex Focus Windows故障排查

Codex 抖音自动切换故障排查

这里整理 Codex Focus Windows 的常见问题：检测不到 Codex 或抖音窗口、Codex 等待权限确认没有切回、抖音没有暂停、下载后打不开等。适合搜索“Codex 切回不工作”“检测不到抖音窗口”“Codex 等待确认没有切回”的用户。

常见故障

检测不到抖音窗口怎么办？

先确认打开的是抖音 Windows 客户端，不是浏览器版抖音。然后检查设置里的 DouyinWindowKeywords 是否包含真实进程名，例如 douyin。

Codex 等待权限确认时没有自动切回怎么办？

确认 Codex Desktop 正在写入本机 session transcript，并检查 CodexWindowKeywords 是否匹配真实 Codex 进程名。再查看最近事件日志，确认是否检测到 waiting approval 状态。

Codex 开始工作后没有切到抖音怎么办？

检查监听是否开启、Codex Desktop 是否正在运行、TaskSwitchDelaySeconds 是否设置过大，以及应用是否能读取 %USERPROFILE%\.codex\sessions 下的 transcript。

抖音没有暂停或没有继续播放怎么办？

播放和暂停依赖窗口中心点击。如果抖音客户端布局变化、窗口被遮挡或焦点没有激活，使用手动测试切换，并尝试调整 ActivationDelayMilliseconds。

下载后打不开怎么办？

先安装 .NET 8 Desktop Runtime，再解压 zip 并运行 CodexFocus.Windows.exe。不要直接在压缩包预览里运行程序。

排查顺序

推荐顺序：先确认运行环境，再确认窗口检测，再确认 Codex transcript 状态，最后调整切换和激活延迟。这样能区分是运行环境问题、窗口匹配问题，还是状态检测问题。

  • 安装 .NET 8 Desktop Runtime。
  • 打开 Codex Desktop 和抖音 Windows 客户端。
  • 在 Codex Focus Windows 中确认两个窗口都能检测到。
  • 查看最近事件日志，确认是否检测到任务开始、任务完成或等待确认。
  • 短任务频繁切换时，把 TaskSwitchDelaySeconds 调到 1 到 3 秒。

仍然无法解决

打开 GitHub issue，并提供 Windows 版本、应用版本、窗口检测状态、最近事件日志和复现步骤。不要粘贴私有 Codex prompt、transcript、凭据、token 或个人数据。
